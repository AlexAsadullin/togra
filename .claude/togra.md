# Работа с проектом через togra

В этом проекте используется утилита **togra** — она строит и поддерживает
структурный граф проекта в `togra-output/graph.json`. Граф — твой главный
вход в кодовую базу: он экономит токены и даёт полную карту зависимостей
без чтения сырого кода.

## Правила работы

1. **Сначала читай `togra-output/graph.json`.** Файл содержит дерево
   проекта, импорты, классы, функции, методы и связи между ними. В 90%
   случаев его достаточно, чтобы понять, что и где находится.
2. **Заглядывай в исходные файлы только когда графа недостаточно** —
   нужно увидеть конкретную реализацию, отлаживаешь баг или ищешь
   литералы/строки, которых в графе нет.
3. **После любых изменений в проекте обновляй `description` в графе** в
   узлах, соответствующих изменённым файлам, классам, методам, функциям.
   Не оставляй устаревшие описания: они сбивают и тебя, и следующего
   агента. Перестраивай граф командой `togra build --update` (только
   изменённые файлы) — она перепарсит изменённые файлы и сбросит их
   `description` в `""`; затем заново заполни описания затронутых узлов.
4. **Формат и стиль `description`** строго описаны в
   [`togra-output/AGENT_GUIDE.md`](../togra-output/AGENT_GUIDE.md) —
   обязательно прочитай гайд перед первой правкой. Без него описания
   окажутся либо болтливыми, либо бесполезными.
5. **Не редактируй другие поля графа.** `_meta`, `imports`, `classes`,
   `methods`, `functions`, `parameters`, `returns`, `calls_*`, `extras`
   — это плоды парсера; они перезапишутся при следующем `togra build`.

## Полезные команды togra

```bash
togra build --update     # перепарсить изменённые файлы (по умолчанию)
togra build --full       # полный пересчёт графа
togra info               # статистика по последней сборке
togra tokens --graph     # оценить размер графа в токенах
togra tokens .           # оценить размер исходников
```

## Чек-лист перед завершением задачи

- [ ] Изменения в коде внесены и проверены.
- [ ] `togra build --update` запущен — граф актуален.
- [ ] Поля `description` затронутых узлов заполнены по
      [`AGENT_GUIDE.md`](../togra-output/AGENT_GUIDE.md).
- [ ] Структура `graph.json` не повреждена (валидный JSON, поля
      `_meta`/`imports`/... не тронуты вручную).
